# 2026년 서울 상권 매출 성장률 추정 모델

## 목적과 범위

서울시 행정동·업종별 추정매출의 2026년 분기별 전년 동기 대비 성장률을 추정한다. 2021~2025년 분기별 자료를 사용하고, 2025년 4분기를 마지막 입력 시점으로 고정한다. 매출 자료가 있는 업종을 대상으로 하며 매출 라벨이 없는 업종은 학습하거나 결과를 생성할 수 없다.

추정 대상은 행정동에 집계된 업종별 매출이다. 개별 점포의 매출, 창업 성공 확률, 투자 수익률을 뜻하지 않는다. 2026년 자료를 입력하지 않으므로 2026년의 상권 변화를 직접 관측한 결과가 아니다. 2026년 11월 기준 1~3분기는 이미 끝난 기간에 대한 추정이며, 4분기는 진행 중인 기간에 대한 추정이다.

## 예측 대상

각 분기를 별도 예측 대상으로 정의한다. 2025년 4분기까지의 정보로 2026년 1~4분기를 각각 1~4분기 앞서 직접 추정하며, 앞선 분기의 예측값을 다음 분기의 입력으로 사용하지 않는다.

```text
2026년 n분기 성장률 = 2026년 n분기 추정매출 / 2025년 n분기 추정매출 - 1
```

예를 들어 결과가 `0.05`면 전년 같은 분기 대비 5% 성장 추정이다. 분모인 2025년 해당 분기의 매출이 0이거나 없으면 성장률을 계산할 수 없다. 결과가 없는 지역이나 업종을 0% 성장으로 해석하지 않는다.

입력은 기준 시점까지 관측된 매출 이력과 확보된 점포 지표를 사용한다. 기준 시점 이후의 매출이나 점포 정보를 입력에 넣지 않는다. 실제 사용하는 특징과 결측 처리 방식은 실행 산출물과 코드에 기록한다.

## 검증 방향

2026년 정답은 학습 자료에 포함되어 있지 않으므로 과거 연도를 같은 방식으로 나누어 점검한다.

| 단계 | 예측 기준 시점 | 예측 대상 | 용도 |
|---|---|---|---|
| 검증 | 2023년 4분기 | 2024년 1~4분기 | 후보 모델 선택 |
| 시험 | 2024년 4분기 | 2025년 1~4분기 | 선택한 방법의 후향 평가 |
| 2026년 추정 | 2025년 4분기 | 2026년 1~4분기 | 2026년 결과 생성 |

각 단계에서 그 단계의 기준 시점 이후 라벨은 학습에 사용하지 않는다. 예를 들어 2024년 후보를 비교할 때 2024년 정답을 학습에 넣지 않는다. 2025년 시험 정답은 후보 선택에 사용하지 않는다. 평가 후 최종 모델을 2025년까지의 가능한 이력으로 다시 학습한다면 평가 모델과 최종 모델이 다르다는 점을 산출물에 표시한다.

예측값은 성장률 0% 같은 단순 기준과 비교하고, 분기별·업종별 표본 수와 평균 절대 오차(MAE)를 함께 확인한다. 성장률을 비율로 표현할 때 MAE `0.05`는 5퍼센트포인트다. MAE를 성공 확률이나 정확도 백분율로 표시하지 않는다.

현재 확보한 자료는 2026년 11월 3일에 확보한 수정 스냅샷이며, 과거 최초 공개 시점과 당시 데이터 버전은 확인되지 않았다. 따라서 위 평가는 **현재 스냅샷을 기준으로 시간을 나누어 수행하는 후향 시뮬레이션**이다. 과거에 실제로 사용할 수 있었던 정보만으로 얻은 실시간 성능이라고 주장할 수 없다.

## 자료 품질과 해석상 주의

- 2021~2025년은 분기별 자료가 있지만, 같은 행정동·업종에 모든 분기가 존재한다는 뜻은 아니다. 필요한 이력이 부족한 조합은 제외 사유를 남긴다.
- 2025년 4분기 스냅샷에는 매출이 기록된 63개 업종이 있다. 점포 자료에만 있고 매출 자료가 없는 업종은 매출 성장률 모델에서 제외한다.
- 업종별·지역별 표본이 적으면 오차가 불안정하다. 특히 고시원은 2025년 4분기 기록이 1행이어서 결과를 일반화하기 어렵다. 표본 수와 제외·경고 사유를 함께 확인한다.
- 전년 동기 매출이 매우 작으면 성장률과 오차가 비정상적으로 커질 수 있다. 원인을 살펴보고 표본 수와 분포를 함께 확인하며, 임의로 값을 0으로 바꾸거나 결과를 보장된 값으로 표현하지 않는다.
- 2026년 경기 변화, 신규 점포, 정책 변화는 2025년까지의 데이터만으로 직접 반영할 수 없다. 더 최신의 공식 자료가 확보되면 기준 시점과 예측 방식을 다시 검토한다.
- 이 모델은 실험용이다. 현재 상권 상태나 사업성에 대한 확정 판단 대신 데이터 기준일과 평가상 한계를 표시한다.

## 추가 확인 사항

- 데이터 출처·이용 조건, 원본 파일 지문과 스냅샷 취득일을 기록한다.
- 지역 코드와 업종 분류가 각 분기에서 일관적인지, 매출 추정 방식에 변경이 없는지 확인한다.
- 2026년 분기별 공식 자료가 확보되면 같은 기준으로 예측과 실제를 비교하고 오차를 갱신한다.
- 백엔드 연동 시 기준 분기, 예측 대상 분기, 데이터 기준일, 모델 버전, 추정치와 경고를 함께 전달한다.

## 실행 및 산출물

프로젝트 루트에서 다음 명령을 실행한다. 원본 매출·점포 파일과 기존 실험의 원본 지문 manifest, 가공 스냅샷이 필요하다. 이미 존재하는 출력 폴더는 덮어쓰지 않으므로 재실행할 때는 새 경로를 지정한다.

```bash
PYTHONPATH=src OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m scripts.forecast_2026 \
  --input data/processed/seoul/seoul-all-snapshot-20261103.csv \
  --output artifacts/seoul-forecast-2026-new \
  --snapshot-at 2026-11-03 --as-of 2026-11-04 \
  --manifest artifacts/seoul-all-industries-retrospective-20261103/source-manifest.json \
  --raw-root data/raw/seoul
```

`--as-of`는 실제 결과 생성 시 분석 날짜를 지정하며, 스냅샷 취득일보다 이를 수 없다. 기존 실행본은 `artifacts/seoul-forecast-2026-20261104/`다. `forecast-2026.csv`는 행정동·업종·대상 분기별 성장률, 기준 매출, 환산 매출과 경고를 포함한다. `summary.json`은 데이터와 코드 지문, 후보별 검증·시험, 분기·업종별 지표, 제외 내역을 포함한다. 선택 모델 `model.joblib`, 최적 학습 후보 `learned-model.joblib`, 비교용 `ridge-model.joblib`도 저장한다. Ridge는 이번 시험에서 오차가 매우 커 참고용이다.

`joblib` 파일은 신뢰하는 출처의 파일만 사용한다. 모델 자체의 `predict`에 원시 입력을 직접 넣으면 동일한 결과가 나오지 않는다. 공통 특징 생성과 입력 변환을 거치는 코드의 `year_rows`와 `predictions`를 사용해야 한다. 스냅샷과 모델 파일은 Git 제외 대상이다. **기존 FastAPI나 Docker 테스트 API는 이 산출물을 불러오지 않는다.** 백엔드 연동은 별도 구현과 계약 검토가 필요하다.

## 실제 스냅샷 실험 결과 (2026-11-04)

매출이 있는 63개 업종 중 필요한 이력이 갖춰진 62개 업종에서 16,002개 행정동·업종 조합의 분기별 결과 64,008건을 생성했다. 고시원 `CS200036`은 필요한 연속 이력이 부족해 결과가 없다. 2026년 추정 대상에서 이력 부족으로 제외한 항목은 5,536건이다.

2024년 검증의 평균 절대오차 기준으로 전체 업종을 함께 학습하는 Huber SGD가 0% 성장 기준 및 Ridge보다 낮아 선택됐다. 2025년 시험은 후보 선택 후 별도 평가했으며, 최종 모델은 2025년까지의 라벨을 포함해 다시 학습했다. 다음은 원본 성장률을 대상으로 계산한 후향 시험 결과다.

| 2025년 시험 후보 | 평균 절대오차 | 중앙 절대오차 |
|---|---:|---:|
| 선택 모델: Huber SGD | 67.63%p | 15.09%p |
| 0% 성장 기준 | 71.21%p | 16.50%p |
| Ridge 비교 후보 | 11,477.16%p | 3,057.09%p |

2025년 시험 표본 63,878건 중 전년 동기 매출이 100만 원 미만인 경우가 280건, 실제 성장률 절댓값이 100%를 넘는 경우가 3,346건이다. 작은 분모와 극단값의 영향을 받아 평균 오차가 매우 크다. 결측이나 극단적인 목표값을 0으로 치환하지 않았으며, 모델의 성장률 예측 하한만 매출이 음수가 되지 않도록 -100%로 제한한다. 정확한 가용성이나 전향 성능 검증이 되기 전에는 사업성 판단에 사용하지 않는다.
