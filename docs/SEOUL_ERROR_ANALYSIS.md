# 서울 공동 모델의 오차 분석

## 범위와 방법

서울·경기 공동 모델의 **평가용** 모델을 사용해 서울의 2025년 4분기 검증 16,002건을 분석했다. 이미 기존 작업에서 결과를 확인한 2026년 2분기 시험 15,961건도 별도 재사용 진단으로 기록했으며, 독립 시험이나 성능 개선의 근거가 아니다. 최종 재학습 모델은 평가용 모델과 다르다.

서울 자료는 행정동·서비스 업종별 추정매출이며, 한 표본은 해당 조합의 분기별 원본 매출 관측값에 대한 전년 동기 대비 성장률이다. 오차는 예측 성장률과 실제 성장률의 절댓값이다. 실제 과거 공개본을 확인하지 못한 최신 수정 스냅샷을 사용했으므로 과거 실시간 성능은 아니다. 서울 원본의 단위는 원화이고, 아래 기준 금액은 **전년 동기 원본 추정매출 관측값**이다.

## 주요 결과: 2025년 4분기 검증

- 평균 절대오차는 **70.28%p**, 중앙 절대오차는 **12.56%p**, 90백분위 오차는 **57.88%p**다.
- 오차가 가장 큰 1%인 161건이 전체 절대오차 합계의 **64.61%**를 차지했다. 많은 예측이 동일한 규모로 틀린 것이 아니라 일부 큰 오차가 평균을 높인다.
- 전년 동기 매출이 1천만원 미만인 **839건**은 전체 검증 표본의 약 5.24%지만 오차 합계의 **60.07%**를 차지했다. 작은 분모가 높은 성장률과 오차를 만들 수 있으나, 모든 급변이 오류라는 뜻은 아니다.

| 전년 동기 원본 추정매출 관측값 | 표본 | 평균 오차 | 중앙 오차 | 전체 오차 합 기여 |
|---|---:|---:|---:|---:|
| 0원 초과 ~ 100만원 미만 | 75 | 2,608.47%p | 233.21%p | 17.40% |
| 100만원 이상 ~ 1천만원 미만 | 764 | 628.08%p | 44.81%p | 42.67% |
| 1천만원 이상 ~ 1억원 미만 | 3,730 | 59.18%p | 22.07%p | 19.63% |
| 1억원 이상 ~ 10억원 미만 | 7,335 | 23.64%p | 12.11%p | 15.42% |
| 10억원 이상 | 4,098 | 13.40%p | 7.25%p | 4.88% |

구간은 서로 겹치지 않는다. 구간별 수치는 해당 자료의 후향 기술통계로, 금액을 기준으로 표본을 삭제하거나 모델의 활용 가능성을 보장하는 기준이 아니다.

## 업종과 행정동

각 순위는 **2025Q4 전체 오차 합계에 대한 기여** 기준이며, 지역·업종 자체의 위험도 순위가 아니다. 표본 수가 다르고 일부 극단값이 평균에 큰 영향을 주므로 중앙 오차도 함께 본다. 명칭은 서울의 2025년 원본 코드 명칭을 참고했으며, 지역 경계·코드 체계의 역사적 동등성을 입증하지 않는다.

| 업종 | 표본 | 평균 오차 | 중앙 오차 | 전체 오차 합 기여 |
|---|---:|---:|---:|---:|
| 의료기기 | 166 | 1,295.55%p | 32.36%p | 19.12% |
| 시계 및 귀금속 | 234 | 548.07%p | 50.58%p | 11.40% |
| 반찬가게 | 293 | 255.90%p | 17.01%p | 6.67% |
| 운동·경기용품 | 147 | 327.02%p | 29.07%p | 4.27% |

| 행정동 | 표본 | 평균 오차 | 중앙 오차 | 전체 오차 합 기여 |
|---|---:|---:|---:|---:|
| 가락본동 | 45 | 4,413.32%p | 9.13%p | 17.66% |
| 한강로동 | 46 | 1,111.44%p | 13.39%p | 4.55% |
| 군자동 | 44 | 964.45%p | 15.19%p | 3.77% |
| 쌍문4동 | 23 | 1,730.69%p | 14.88%p | 3.54% |

예를 들어 가락본동 의료기기의 원본 추정매출은 2024Q4 약 433만원에서 2025Q4 약 86.21억원으로 크게 바뀌었다. 두 시점의 점포 수는 각각 25개로 같지만, 점포 수만으로 매출의 실제 변화, 추정·표본 변화, 제공기관 정정 또는 원본 오류를 구분할 수는 없다. 제공기관에 추정 방식·표본·정정 이력을 확인해야 한다.

## 결측 및 개선 시 유의점

2025Q4의 매출 조합 16,718건 중 이전 4분기 중 하나라도 없는 716건을 평가에서 제외해 16,002건이 남았다. 0분모 추가 제외는 없었다. 2026Q2는 16,659건 중 698건의 이력이 부족해 15,961건을 재사용 진단했다. 누락을 0으로 채우지 않았으며, 이력 부족 사례는 평가에서 빠져 결과에 표본 선택 편향이 있을 수 있다.

분모가 작은 행을 임의로 제거하거나 실제 성장률을 임의로 잘라 평균 오차만 낮추지 않는다. 원본의 큰 변화와 공개·정정 이력 확인, 비율의 불안정성을 고려한 모델링, 중앙오차·상위 분위·표본 수의 병행 보고와 새로운 시기의 독립 평가가 필요하다. `reports/seoul-unified-error-20261109/`에는 행별·지역별·업종별·분모 구간별 결과와 출처·코드·모델 SHA가 들어 있다. 행별 파일은 실제 집계값이므로 외부에 자동 공개하지 않는다.

## 저매출 구간의 사후 탐색

모델 평가 결과를 확인한 **이후** 탐색 차원에서, 2025Q2 학습 표본의 전년 동기 원본 추정매출 관측값 하위 5백분위인 약 **1,054만원**을 기준으로 2025Q4 검증 표본을 나눴다. 기준값은 학습 표본에서 계산했지만, 이 구분 자체가 기존 결과를 본 뒤 선택됐으므로 독립적으로 확정된 기준은 아니다.

| 구간 | 표본 | 전체 대비 | 공동 모델 MAE | 0% 성장 기준 MAE |
|---|---:|---:|---:|---:|
| 기준 미만 | 887 | 5.54% | 767.99%p | 825.43%p |
| 기준 이상 | 15,115 | 94.46% | 29.33%p | 38.21%p |

기준 이상 구간의 29.33%p는 **선별된 표본의 오차**이며 전체 모델의 오차가 아니다. 어떤 행도 자동 제외하지 않았고 예측이나 운영 API에 이 기준을 적용하지 않았다. 기존에 확인한 2026Q2의 같은 구분도 `summary.json`에 탐색 결과로 기록하며 독립 시험으로 취급하지 않는다.

## 재실행

```bash
PYTHONPATH=src:. OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m scripts.analyze_unified_seoul \
  --source data/processed/seoul/seoul-2021-2026q2-20261104.csv \
  --names 'data/raw/seoul/sales/서울시 상권분석서비스(추정매출-행정동)_2025년.csv' \
  --model-root artifacts/unified-growth-research-20261109 \
  --output reports/seoul-unified-error-new
```

기존 경로는 덮어쓰지 않는다. 운영자가 신뢰하는 로컬 모델만 사용한다. SHA는 무결성 확인이지 신뢰할 수 없는 joblib을 안전하게 만들지 않는다.


## 서울 이력 확대 공동 모델 (2026-11-09)

동일한 4개 분기 비율 특징과 출처 indicator, 원천별 50:50 가중치를 유지하면서 서울 학습 이력을 2022Q2~2025Q2로 확대하고 경기 학습은 기존 2025Q2를 사용했다. 2025Q3을 비운 뒤 같은 2025Q4 평가 표본에서 비교했다.

| 2025Q4 검증 | 기존 공동 모델 MAE | 이력 확대 후보 MAE |
|---|---:|---:|
| 서울 | 70.28%p | 69.61%p |
| 경기 | 38.83%p | 38.35%p |

서울 중앙 오차는 12.56%p에서 12.38%p로 낮아진 반면 p90은 57.88%p에서 58.01%p로 높아졌다. 서울 **전용** 모델의 2024Q2·2024Q4·2025Q2 롤링 실험에서는 이력 확대가 모든 시점에서 개선되지 않았다. 이미 본 2025Q4 검증으로 수행한 탐색이며 독립 성능을 주장할 수 없다. 2026Q2는 비교하지 않았다.

평가 후 2026Q2까지 서울 277,750행·경기 152,405행으로 후보를 다시 학습했다. 최종 후보는 평가 모델과 다르며, 기존 통합 모델·FastAPI를 교체하지 않는다. `artifacts/unified-extended-history-research-20261109/`의 모델과 메타데이터는 연구 전용이다.

## 학습시 극단 성장률 제외 실험

서울 훈련 라벨에서만 계산한 1·99백분위를 적용해 학습 일부를 제외했다. 경기 학습과 **검증 전체 표본은 유지**하고 원천별 가중치를 다시 맞췄다. 값이 극단적이라는 사실은 오류 증거가 아니다.

| 서울 학습 처리 | 서울 제외 행 | 서울 2025Q4 MAE | 경기 2025Q4 MAE |
|---|---:|---:|---:|
| 전체 유지 | 0 | 69.61%p | 38.35%p |
| 상위 1% 제외 | 2,138 | 72.92%p | 39.49%p |
| 상·하위 1% 제외 | 4,276 | 73.00%p | 39.34%p |

제외 후보는 양쪽의 전체 검증 MAE가 악화되어 채택하지 않았다. 임계값과 실험은 오류 분포를 살펴본 뒤 탐색적으로 결정했으며 독립 실험은 아니다. `artifacts/seoul-outlier-study-20261109/`에 비교 모델과 지표가 있다.

## 예측 전 이력으로 보류하는 가정

기존 공동 평가 모델의 서울 2025Q2 훈련 입력에서 두 신호를 정했다. 비교 기준 전년 매출이 훈련 표본 하위 5%인 약 1,054만원보다 작은 경우 또는 직전 4개 분기 중 최대 전분기 증가율이 훈련 상위 5%인 약 +206.66%를 초과하는 경우다. 예측할 대상 분기의 실제 매출이나 실제 오차는 신호에 사용하지 않는다. 기준은 기존 오차를 본 뒤 탐색한 것이며 변동이 실제 오류라는 의미가 아니다.

2025Q4에서 두 신호 중 하나에 해당하는 1,546건(9.66%)을 보류한다고 가정하면, 나머지 14,456건(90.34%)의 조건부 MAE는 20.63%p이며 같은 표본의 0% 기준 MAE는 27.10%p다. 전체 16,002건의 MAE 70.28%p와 동일 범위의 성능으로 비교할 수 없다. 평가 자체는 실측 라벨과 네 분기 이력이 모두 있는 표본에 한정된다. 2026Q2는 이미 본 재사용 진단이다.

연구 코드의 신호 함수는 네 분기 입력만 사용하지만, 평가 작업은 대상 분기의 실측 라벨이 필요하다. 이후 사용자의 요청으로 입력 전용 네 신호 보류 정책을 통합 연구 API에 적용했다. 정책은 전향 검증이 없는 탐색 기준이며 기존 두 신호 평가와 구분한다. 원본 행은 삭제하지 않는다. [신호 연구 결과](../reports/seoul-presignal-20261109/summary.json)에서 겹침·제공률·지표를 확인한다.

## 재현: 개선 및 제외 연구

다음 공통 입력은 이전 공동 모델과 같은 원본 파일 및 매니페스트다. 새 출력 경로를 사용한다.


같은 인자에서 모듈명을 `scripts.study_seoul_train_outliers`로 변경하고 새로운 출력 경로를 지정하면 학습 제외 비교를 재현한다. 사전 신호 검토는 다음처럼 실행한다.

```bash
PYTHONPATH=src:. OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
```

서울시 매출 API에서 2026Q3을 2026-11-09에 다시 조회했으나 `INFO-200`(해당 조건 자료 없음)을 반환했다. 따라서 새 분기 독립 평가는 아직 수행하지 못했다.


## 2026-11-09 통합 연구 API 보류 정책

사용자 요청에 따라 서울에서 전년 동기 저매출, 최근 분기 저매출, 분기 매출 급증과 급감의 네 신호 중 하나라도 해당하면 통합 연구 API가 성장률을 보류한다. 두 저매출 및 급변 임계값은 기존 서울 훈련 이력에서 정한 5·95백분위이며 데이터 오류의 증거가 아니다. 신호는 모델 추론 전 4개 입력 분기만 사용하고 사유와 한국어 설명을 반환한다. 현재 공동 모델과 서울 원천/평가 모델 지문에만 적용되며 경기 원화 임계값은 미검증으로 적용하지 않는다.

네 신호를 이미 확인한 2025Q4 검증의 라벨·이력 완비 표본 16,002건에 적용한 사후 연구에서는 1,890건(11.81%)을 보류하고 나머지 14,112건의 조건부 MAE는 20.19%p였다. 이 수치는 전체 요청 제공률이나 전향 성능, 최종 모델 독립 평가가 아니다. 새 기간 검증이 필요하다. 재현 자료와 기준은 [통합 API 문서](UNIFIED_API.md) 및 `reports/seoul-guard-policy-20261109/summary.json`에 기록한다.


원본 열명은 `당월_매출_금액`이고 서울 서비스는 분기 단위로 제공한다. 세 달 합계인지 등 금액의 시간 단위는 별도 확인 전 단정하지 않으며 원본을 3배하지 않는다. 실제 사례의 금액·건수 세부 구성, 정책의 업종별 영향과 점포 이력 후보 결과는 [서울 원본 진단](SEOUL_SOURCE_DIAGNOSIS.md)을 참고한다.
