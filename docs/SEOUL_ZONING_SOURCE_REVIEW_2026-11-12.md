## VWorld 표본 확인

2026-11-12 KST에 `LT_C_UQ111` 레이어를 서울시청 인근 좌표 `126.9780, 37.5665`의 작은 범위로 조회했다. 서버는 `OK`와 `MultiPolygon` 피처 1건을 반환했다. 원본 SHA-256은 `8cef1489ce75a25a0f17425867dc35c09817cd923e4a56c9de07a0949caa7fd2`다. 읽기 전용 점·도형 포함 여부 검사에서 요청 중심점이 반환 도형 안에 있음을 확인했다.

속성 `uname`은 `일반상업지역`이다. [국토계획법 시행령 제30조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=108366)에 따르면 일반상업지역은 도시지역의 **상업지역** 세분류다. 따라서 **이 조회 지점**의 표본은 상업지역으로 해석할 수 있다. 이 결과를 중구 전체나 행정동 전체의 용도지역으로 확대하지 않는다.

원본에는 `dyear='2023'`, `dnum='0511'`, `sido_name='서울특별시'`, `sigg_name='중구'`도 있었다. `dyear`와 `dnum`의 공식 필드 정의를 확인하지 못했으므로 `2023`을 지정일·효력일·공개일로 쓰지 않는다. 수집 메타데이터의 `effective_at`은 `null`이고 `training_eligible`은 `false`다. 키와 원본 도형은 이 문서에 복사하지 않았다. 원본은 Git 제외 경로 `data/raw/nationwide/zoning/vworld/20261111/`에 보관되어 있다.

서울시는 이 자료의 좌표계를 **EPSG:5174**, 인코딩을 **windows-949**로 안내한다. 저작권자는 서울특별시, 이용허락은 공공누리 제1유형(출처표시)이며, **법적 효력이 없는 참고자료**라고 명시한다. 현재 목록에는 2021~2022년 ZIP이 없다. 파일 수정일만으로 각 도형의 법적 효력일 또는 당시 실제 공개일을 증명할 수 없다. 개별 ZIP의 직접 다운로드 URL과 로그인 요구 여부도 아직 검증하지 않았다.

[SGIS 자료제공 목록](https://sgis.mods.go.kr/view/pss/openDataIntrcn)은 센서스용 행정구역 경계(읍면동) SHP를 **2001~2025년 매년** 제공한다고 안내한다. [SGIS 자료제공 안내](https://sgis.mods.go.kr/view/pss/dataProvdIntrcn)는 기준시점 6월 30일과 **EPSG:5179**를 명시한다. 다만 [SGIS 개발자 문서](https://sgis.mods.go.kr/developer/html/openApi/api/data.html)의 읍면동 `adm_cd`는 **7자리**이므로 PickPlace의 MOIS H10 행정동 코드에 자릿수만 맞춰 연결할 수 없다. 코드 대응과 도형의 실제 경계를 검증해야 한다.

## 학습 전 확인할 조건

1. 서울 ZIP을 파일별로 받아 내부 SHP/DBF/PRJ, 용도지역 세부 코드, 도형 중복·누락, 좌표계와 출처를 검증한다. 공개일과 효력일은 별도로 확인한다.
2. 평가 분기 당시 이용 가능했던 용도지역 스냅샷과 같은 시점의 행정동 경계를 연결한다. 행정동별 주거·상업·공업·녹지 **면적 비율과 미분류 비율**을 계산하고, SGIS 7자리와 서비스 H10의 대응을 검증한다. 한 지점의 분류를 동 전체의 값으로 사용하지 않는다.
3. 2021~2022년은 현재 확인된 공간 스냅샷으로 복원할 수 없으므로 그 기간에 오늘의 분류를 소급하지 않는다. 시점과 코드가 확인된 표본에서 기존 매출·업종 기준선과 동일한 시간순 평가로 용도지역 특징의 추가 효과를 검증한다.
4. 위 조건과 자료의 사용 범위를 확인하기 전까지 용도지역을 매출 예측 모델의 학습 특징이나 매출 변화의 원인 설명에 넣지 않는다. 현재 조회 결과는 위치별 참고 정보로만 취급한다.

이번 작업은 기존 모델·FastAPI를 수정하거나 학습을 실행하지 않았다. 새 문서만 추가했으며 실제 원본·키는 Git에 포함하지 않는다.
