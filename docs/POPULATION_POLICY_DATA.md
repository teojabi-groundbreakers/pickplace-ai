# 인구·정책 데이터 확보 계획

확인일: 2026-11-09. 2026-11-09 전문가 자문에서 제안된 인구·정책 자료를 현재 서울·경기 행정동별 전년 동기 매출 성장률 연구에 맞춰 정리했다. 링크는 원천 제공기관의 자료 상세 또는 조회 화면이다. 자료 사용 가능 여부와 최신 제공 범위는 수집 시 다시 확인한다.

API 수집 명령과 인증 준비는 [인구·정책 API 수집 문서](POPULATION_POLICY_API.md)를 참고한다.

## 현재 보유 현황

| 자료 | 상태 | 다음 단계 |
|---|---|---|
| 서울 상주인구·길단위인구 | 로컬 원본 CSV에 각각 2021Q1~2026Q2의 22개 분기가 등장 | 재다운로드보다 지역·분기별 누락과 기준·공개시점 검토 및 연계 가능성 확인이 우선이다. 전체 동·분기 완전성은 미검증이다. |
| 전국 주민등록 인구 | 2026년 10월 시도·시군구·읍면동 파일 보유 | 2021~2026년 이전 월별 이력이 필요하다. 2026년 10월은 이전 분기 예측에 사용할 수 없다. |
| 경기 인구 이동·직장인구 | 위의 주민등록인구 외 별도 이력 미확인 | 아래 경기 목적인구 후보의 기간·정의·이용 조건을 확인한다. |
| 정책 데이터 | 로컬 원천 자료 미확인 | 지역화폐 이력과 지원사업 공고를 목적별로 검토한다. |

서울 인구 원본의 행정동 코드는 8자리이고 보유 주민등록 인구의 행정기관코드는 10자리다. 형식만 보고 자릿수를 자르거나 덧붙이지 않는다. 코드별 공식 대응·변경 이력·경계 및 시점별 유효성을 확인한다. 현재 공동 모델에는 인구·정책 데이터가 포함되지 않았다.

**먼저 받을 설정:** 주민등록 인구 조회에서 행정동별·월간, 전체 읍면동 또는 서울·경기, 2021-01~2026-06, 등록구분을 일관되게 선택하고 남녀 및 10세 연령구간을 조회해 CSV로 보관한다. 페이지의 기간·지역 선택 및 내려받기 제한에 맞춰 연도별 또는 월별로 나눠 받아도 된다. 우선 분기말 3·6·9·12월만 확보한 뒤, 월별 변화를 검토할 때 전체 월을 보충하는 방법도 가능하다. 자료는 매월 말 기준이며 원칙적으로 다음 달 1일 12시 이후, 주말·공휴일이면 다음 평일에 공표된다. 실제 예측 기준일에 공개됐는지를 따로 확인한다. ### 사용자 안내용 후보

- [기업마당 지원사업 공고 파일](https://www.data.go.kr/data/3034791/fileData.do): 사업명, 기관, 신청 기간과 공고 URL을 확인할 수 있다. 서울·경기 등 대상 지역과 실제 모집 여부를 원문에서 확인한다.
- [기업마당 지원사업 API](https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi): 인증 신청 후 분야·지역 등 공고를 조회하는 후보. [공공데이터포털 API 설명](https://www.data.go.kr/data/15157820/openapi.do)상 시간 범위는 당해년도이고 공공누리 3유형(출처표시·변경금지)으로 표기돼 있다. 과거 공고 전체 보유 여부와 가공·서비스 활용 조건을 제공처별로 확인한다.
- [K-Startup 지원사업 공고 API 조회](https://nidview.k-startup.go.kr/view/public/kisedKstartupService/announcementInformation): 지역·대상·접수기간별 창업지원 공고 조회 후보. 인증·재사용 조건과 과거 이력 범위는 추가 확인한다.

지원사업 **공고는 사업이 실제 집행됐거나 해당 상권이 지원을 받았다는 증거가 아니다.** 모델 라벨과 혼동하지 않으며, 안내 화면에서 공고일·신청기간·대상·원문 링크를 분리한다.

## 3. 수집·연계 기준

1. 원본은 원본 경로에 보존하고 출처, 이용 조건, 기준 기간, 실제 다운로드일·공개일, 코드 체계와 파일 지문을 기록한다. 가공이나 외부 배포는 각 자료의 조건을 확인한다.
2. 현재 서울·경기 매출은 행정동·업종·분기 기준이다. 인구는 관측 월과 분기를 정확히 유지하고 분기말 또는 분기 평균 중 사용할 방식을 사전에 정해 비교한다. 거주자와 생활인구는 의미가 다른 지표다.
3. 예측에 들어가는 자료는 **해당 예측 기준일에 이미 공개돼 사용할 수 있었던 값만** 허용한다. 최신 수정 스냅샷의 과거 공개 이력이 확인되지 않으면 진정한 과거 시점 검증으로 표시하지 않는다.
4. 광역·시군·자치구 수치를 행정동에 연결하더라도 상위 지역 공통 특성으로 구분한다. 동별 집행·수혜·매출로 표기하거나 값을 동별로 합산하지 않는다.
5. 원본에 없는 값은 0으로 임의로 채우지 않는다. 새 인구·정책 특징의 성능 향상 여부는 동일 기간·표본·평가 기준에서 기존 모델과 비교한다.

참고: 서울의 상권분석서비스는 분기 자료가 통상 2개월 뒤 갱신될 예정이라고 안내하지만, 이 예정이 개별 분기의 실제 공개일 증거는 아니다. [서울시 서비스 안내](https://golmok.seoul.go.kr/introduce.do)
