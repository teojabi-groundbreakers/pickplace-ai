# AI 전문가 자문 기록

- **자문일:** 2026-11-09
- **목적:** PickPlace의 데이터 수집, 매출 성장률 모델과 서비스 제공 방향 검토
- **기록 기준:** 자문 후 전달받은 메모를 정리한 내용이다. 문장이 끝나지 않은 발언과 답변이 기록되지 않은 항목은 추측하지 않고 추가 확인 대상으로 남긴다.
- **사전 질문:** [AI 멘토링 질문](AI_MENTORING_QUESTIONS.md)

## 1. 자문 내용

### 서로 다른 매출 자료의 공동 학습

**질문:** 서울 추정매출과 서울 외 지역의 카드매출처럼 수집 기준, 집계 방식과 범위가 다를 수 있는 자료를 하나의 모델로 학습해도 되는가? 다른 방향이 더 적절한가?

**메모에 적힌 의견:**

> 하나로 합쳐도 될 거 같긴 한데, 카테고리가 달라서 A매장
>
> 데이터 확보가 우선

공동 학습이 가능할 수 있다는 의견으로 기록하되, 첫 문장의 뒷부분은 문맥이 완성되지 않아 의미를 확정하지 않는다. 어떤 카테고리의 차이를 말하는지와 매장 사례의 의미는 추가 확인이 필요하다. 공동 모델 사용이 확정됐거나 자료 간 동등성이 검증됐다는 뜻은 아니다.

**후속 검토:** 지역별 매출 자료를 확보하고, 자료마다 대상 지역·업종 분류·금액 단위·집계 범위·기준 기간과 공개 시점을 확인한다. 서울 외 모든 지역의 카드매출 확보는 아직 확인되지 않았다. 현재 경기 자료는 단위·집계 방식·지역 경계가 미검증인 검토용 후보다.

### 예측이 어려운 사례의 학습 포함 여부

**질문:** 저매출이나 급격한 매출 변화가 있는 사례를 학습에도 포함하고, 결과를 제공할 때만 예측을 보류하는 방식이 적절한가?

**메모에 적힌 의견:** 데이터 확보가 어려우면 학습 데이터를 추가할 방안을 고민한다.

이는 데이터 확충 방안을 검토하자는 의견으로 기록한다. 해당 사례를 학습에 반드시 포함하거나 제외하라는 결론은 메모에 없다. 추가 자료의 출처·이용 가능성·품질·시간 범위와 자료 부족의 원인을 살펴본 뒤 학습 방식과 평가를 비교한다. 학습에서 제외한 원본 자료는 삭제하지 않는다.

### 2026년 3분기 자료 없이 성능 검증

**질문:** 2026년 3분기 최신 자료 없이 성능을 어떻게 검증해야 하는가?

**메모에 적힌 답변:** 별도로 기록되지 않았다. 검증 방법은 미결정이며 추가 확인이 필요하다.

현재 확보한 과거 자료로 시간순 평가를 검토할 수 있으나, 이미 반복해 살펴본 분기는 독립 시험으로 취급하지 않는다. 최신 스냅샷의 과거 공개·정정 시점이 확인되지 않은 점과 최종 재학습 모델의 독립 성능이 확인되지 않은 점도 유지한다.

### 외부 요인 자료

**메모에 적힌 의견:** 인구수, 정책 등 외부 요인 자료도 확보할 필요가 있다.

**후속 검토:** 확보 가능한 인구 및 정책 관련 자료의 지역 단위, 관측 기간, 갱신·공개 시점과 기존 매출 자료와의 연계 가능성을 확인한다. 인구나 정책 정보가 예측 오차를 줄인다고 미리 가정하지 않는다. 실제 예측 시점에 알 수 없었던 정보는 학습·평가 입력으로 소급하지 않는다.

### 유사 서비스와 사용자 제공 정보

**메모에 적힌 의견:** 유사한 서비스가 시장에 많으므로 벤치마킹하고 추가할 서비스를 고민한다. AI 결과를 보면서 사용자에게 제공할 내용을 보충한다.

**후속 검토:** 유사 서비스의 제공 기능과 화면, 데이터 출처·기준 시점, 결과 설명과 제한을 확인해 우리 서비스의 추가 기능 후보를 정리한다. 모델의 결과 의미와 검증 상태를 살펴보고 사용자에게 보여줄 수 있는 정보와 보완할 설명을 검토한다. 특정 경쟁 서비스나 기능은 아직 정하지 않았다.

## 2. 후속 작업 후보

| 순서 | 검토 항목 | 구체적으로 확인할 내용 |
|---|---|---|
| 1 | 자료 현황·추가 확보 | 서울·경기와 그 밖의 지역별 매출 자료의 확보 여부, 기간, 집계 기준, 이용 조건과 비어 있는 범위 |
| 2 | 외부 요인 정리 | 인구와 정책 등 자료의 지역 단위, 시점, 공개일과 모델 입력으로 사용할 수 있는 조건 |
| 3 | 공동 학습 설계 | 매출 정의와 업종 분류 차이, 지역별 자료 품질을 확인하고 공동 모델과 지역별 대안을 비교할 기준 |
| 4 | 학습·평가 방법 | 데이터 부족 원인, 저매출·급변 이력의 처리 방식과 시간순 평가 방법. 이미 확인한 기간과 독립 검증의 구분 |
| 5 | 서비스 벤치마킹 | 비교할 서비스 선정 후 제공 기능, 데이터 출처·기준 시점, 결과 표시와 제한 사항 정리 |
| 6 | 사용자 제공 내용 검토 | 실제 AI 응답의 의미·근거·누락 사유를 확인하고 사용자에게 설명할 정보와 기능 후보 정리 |

위 항목은 자문 내용을 바탕으로 정리한 **검토 후보**이며 구현이나 모델 변경이 완료됐다는 의미는 아니다. 외부 데이터를 실제로 확보하거나 서비스를 벤치마킹하지 않았다.

## 3. 추가 확인할 질문

- 공동 학습에 대한 의견에서 말한 **카테고리의 차이와 A매장 사례**는 무엇을 뜻하는가?
- 2026년 3분기 자료 없이 현재 모델을 검증할 때 권장하는 구체적인 기간 분리와 지표는 무엇인가?
- 예측이 어려운 사례를 학습에 포함할지에 관한 의견과, 학습 데이터가 부족할 때 권장하는 확보 방안은 무엇인가?
- 인구·정책 자료에서 우선 확인할 범위와 지역·시간 단위는 무엇인가?
- 벤치마킹할 서비스와 AI 결과에 덧붙이면 유용한 사용자 정보는 무엇인가?
