# 2026년 3·4분기 서울 매출 성장률 연구용 추정

## 목적과 입력 자료

서울시 행정동·업종별 추정매출에 대해 2026년 3분기와 4분기의 **전년 동기 대비 성장률**을 각각 추정한다. 2026년 2분기까지의 매출·점포 자료를 사용하며 두 분기를 각각 1분기와 2분기 앞 대상으로 직접 추정한다. 3분기의 추정값을 4분기 입력에 재사용하지 않는다.

```text
2026년 n분기 전년 동기 대비 성장률
  = 2026년 n분기 추정매출 / 2025년 n분기 추정매출 - 1
```

추정 대상은 행정동·업종 단위의 서울시 **추정매출**이다. 개별 점포의 실제 매출, 수익이나 창업 성공 확률이 아니다. 성장률 0.05는 전년 동기 대비 5% 성장 추정을 뜻한다.

2021~2025년 자료는 2026년 11월 3일 확보한 수정 스냅샷이며, 2026년 1·2분기 매출·점포는 2026년 11월 4일 서울 열린데이터광장 API에서 수집했다. 두 자료의 취득일은 최초 공개일이 아니다. 매출 값은 기관이 제공한 그대로 사용하며, 열 이름만 보고 월 단위라고 판단하거나 3배하지 않는다.

2026년 11월 4일 기준으로 3분기는 이미 종료된 기간에 대한 **사후 추정**, 4분기는 진행 중인 분기에 대한 추정이다. 2026년 3·4분기 매출은 입력에 포함되지 않았다.

## 기존 2026년 추정과 확보한 자료 비교

기존 2026년 연간 모델이 만든 1·2분기 추정과 나중에 수집한 서울시 2026년 1·2분기 추정매출을 같은 행정동·업종·분기로 연결했다. 비교에 사용한 전년 매출 분모는 기존 모델이 사용했던 2025년 스냅샷 값이다. 해당 분모가 이후 서울시에서 수정되었는지는 확인하지 않았다.

| 비교 항목 | 매칭 건수 | 평균 절대오차 | 중앙 절대오차 |
|---|---:|---:|---:|
| 기존 모델, 2026년 1·2분기 합계 | 31,668건 | 108.66%p | 13.68%p |
| 0% 성장 기준, 같은 표본 | 31,668건 | 115.35%p | 16.66%p |

2026년 1·2분기 전체 매출 원본 33,318건 가운데 예측에 대응하는 것은 31,668건이다. 기존 예측 32,004건 중 336건은 해당 분기의 API 자료와 매칭되지 않았고, API 자료 1,650건은 기존 예측이 없었다. 미매칭을 0으로 채우지 않는다.

기존 결과는 2026년 11월에 생성되어 1·2분기가 끝난 뒤의 값이다. 그때 공개된 자료를 뒤늦게 확보해 비교했으므로 이 수치는 **전향 예측 성능이 아니다**. 재현 가능한 비교 절차와 자료 지문은 별도 평가 산출물에 기록한다.

## 최신 자료 활용 방식의 비교

2026년 2분기까지 입력하는 방식의 참고 검증으로, 과거에 같은 간격을 적용해 2025년 3·4분기를 추정했다. 기존 연간 방식은 2024년 4분기를 기준으로, 새 단기 방식은 2025년 2분기를 기준으로 각각 같은 분기를 추정한다. 두 결과는 행정동·업종·대상 분기가 같은 공통 표본에서 비교했다.

| 2025년 후향 시험 대상 | 기존 모델 평균 절대오차 | 새 방식 평균 절대오차 | 기존 중앙 절대오차 | 새 방식 중앙 절대오차 |
|---|---:|---:|---:|---:|
| 3분기 | 66.41%p | 62.56%p | 16.05%p | 13.69%p |
| 4분기 | 72.33%p | 68.92%p | 16.83%p | 14.93%p |

이 비교에서는 최신 분기까지 활용한 방식의 오차가 낮았다. 그러나 하나의 과거 시험 구간을 현재 확보한 수정본으로 평가한 결과이므로 **2026년 3·4분기에도 오차가 줄어든다고 보장할 수 없다**. 과거 최초 공개 시점과 당시 데이터 버전이 확인되지 않아 실제 당시 사용 가능했던 자료만으로 검증한 성능도 아니다.

새 방식은 2024년을 이용해 후보 모델을 선택하고, 2025년 시험 분기는 선택에 쓰지 않는다. 시험 후 최종 모델은 2026년 2분기까지 확보한 라벨로 다시 학습한다. 분기별 후보와 평가, 공통 표본 수는 모델 산출물에 기록한다.

## 오차와 활용 한계

- 매출 규모가 작을 때 전년 동기 매출이 분모가 되어 성장률이 매우 커질 수 있다. 2026년 1·2분기 비교의 평균 오차는 이런 극단값의 영향을 크게 받으므로 중앙 절대오차와 표본 수를 함께 확인한다. 낮은 분모와 작은 업종 표본에는 경고를 표시한다.
- 필요한 과거 이력이나 전년 동기 매출이 없는 지역·업종은 결과를 제공하지 않는다. 결측을 0% 성장으로 간주하지 않는다.
- 인구·면적과 2026년 3분기 이후 경기 변화는 입력으로 반영하지 않았다. 이 실험은 보정된 예측구간, 성공 확률 또는 개별 점포의 사업성 평가를 제공하지 않는다.
- 2026년 3·4분기 공식 추정매출이 확보되면, **이미 생성된 예측을 보존한 상태에서** 대상 분기별 오차와 단순 기준을 비교해야 한다. 과거 추정치를 최신 실제값으로 덮어쓰지 않는다.
- 새 모델은 별도 [연구용 FastAPI·Docker](NEAR_TERM_API.md)로 로컬 호출할 수 있다. 기존 운영 및 후향 재현 API와는 분리되어 있으며, 실제 Spring Boot 연결과 운영 사용은 별도 검증이 필요하다.

## 실제 산출물 및 재실행

`artifacts/seoul-near-term-2026q2-20261104/`의 `forecast-2026-q3-q4.csv`는 분기마다 15,961건, 총 31,922건을 담는다. 매출 제공 63개 업종 중 62개 업종이 포함되고 고시원은 이력 부족으로 제외됐다. 해당 행정동·업종의 학습 이력 여부는 `scope_seen_in_training`과 `warning`에 기록한다. `summary.json`은 데이터·코드 지문과 두 분기의 검증·시험 및 공통표본 비교를 담고, `model.joblib`은 각 예측 거리의 선택 모델을 포함한다.

프로젝트 루트에서 실제 자료를 보유한 경우 새 출력 폴더로 다음을 실행한다.

```bash
PYTHONPATH=src:. OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m scripts.near_term_forecast \
  --historical data/processed/seoul/seoul-all-snapshot-20261103.csv \
  --raw-root data/raw/seoul \
  --old-manifest artifacts/seoul-all-industries-retrospective-20261103/source-manifest.json \
  --output artifacts/seoul-near-term-new --as-of 2026-11-04
```

수집일보다 이른 `--as-of`는 거부한다. 출력 경로가 이미 있으면 덮어쓰지 않는다. 모델은 신뢰하는 출처의 파일만 읽는다. 재추론은 `build_frames`로 관측 이력의 특징을 만든 다음 `predict`를 호출해야 한다. 저장된 모델의 `predict`에 원시 입력을 직접 넣으면 필요한 변환과 성장률 하한을 적용하지 못한다. 학습·추론에 쓰인 특징 코드는 `features.py`와 해당 스크립트에 있으며, 의존 코드와 버전의 지문도 요약에 기록한다.

## 데이터 결합과 기존 추정 평가 재현

기존 원본·스냅샷의 해시와 신규 분기 CSV·메타데이터를 확인하면서 두 취득일을 유지해 결합한다. 기존 출력은 덮어쓰지 않는다.

```bash
PYTHONPATH=src .venv/bin/python -m scripts.combine_seoul_snapshots \
  --historical-input data/processed/seoul/seoul-all-snapshot-20261103.csv \
  --historical-summary artifacts/seoul-all-industries-retrospective-20261103/summary.json \
  --historical-manifest artifacts/seoul-all-industries-retrospective-20261103/source-manifest.json \
  --raw-root data/raw/seoul --periods 2026Q1 2026Q2 \
  --output data/processed/seoul/seoul-combined-new.csv
```

기존 2026Q1/Q2 예측과 현재 서울시 공개 추정매출 비교는 다음 명령으로 재현한다. 새 출력 경로를 지정한다.

```bash
PYTHONPATH=src .venv/bin/python -m scripts.evaluate_forecast_2026 \
  --forecast-dir artifacts/seoul-forecast-2026-20261104 \
  --snapshot data/processed/seoul/seoul-all-snapshot-20261103.csv \
  --sales data/raw/seoul/sales/seoul-api-sales-2026Q1.csv \
          data/raw/seoul/sales/seoul-api-sales-2026Q2.csv \
  --output reports/seoul-previous-forecast-evaluation-new
```

이번 실행 결과는 `data/processed/seoul/seoul-2021-2026q2-20261104.csv`와 `reports/seoul-2026-previous-forecast-evaluation-20261104/`에 저장했다. 가공 데이터·모델·평가 보고서는 Git 제외 대상이다.
