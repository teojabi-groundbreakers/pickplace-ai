# VWorld 법정 용도지역 자료 준비와 연동 조건

작성일: 2026-11-11 (Asia/Seoul)
상태: **API 키 발급 전 준비 문서**. 실제 용도지역 조회, 공식 자료 반입, 모델 재학습 또는 FE·BE 연동 완료를 뜻하지 않는다.

## 선택할 원천과 확인 범위

- 후보 A는 공공데이터포털의 [국토교통부 용도지역지구도(WMS/WFS)](https://www.data.go.kr/data/15058773/openapi.do)다. 지도의 시각화(WMS)와 도형·속성 조회(WFS)를 구분한다.
- 후보 B는 더 구체적인 이름의 [국토교통부 도시지역](https://www.data.go.kr/data/15056805/openapi.do)이다. 포털은 JSON/XML을 안내하지만 **주거·상업·공업·녹지 네 세부 유형과 폴리곤·필드가 실제 응답에 어떻게 나타나는지 아직 검증하지 않았다.** 후보 B가 후보 A의 특정 WFS 레이어와 동일하다고 가정하지 않는다.
- 두 후보의 실제 API 경로, 레이어 ID, 필드명, 페이지 크기, 좌표계, 응답 형식과 완전성은 **발급된 키로 공식 샘플을 조회한 뒤 비교·확정**한다.
- [국토교통부 국토계획구역](https://www.data.go.kr/data/15056802/openapi.do)은 별도 자료다. 이름과 제공 설명만으로 주거·상업·공업·녹지의 전국 완전한 판정 원천이라고 가정하지 않는다.
- 주거·상업·공업·녹지는 **도시지역의 세부 용도지역**이다. 전국에는 관리지역·농림지역·자연환경보전지역도 있으므로 네 가지 중 하나로 강제 분류하지 않는다. [서울시 용도지역 설명](https://www.data.go.kr/data/15046548/fileData.do)
- [공식 카탈로그의 이용허락 정보](https://www.data.go.kr/catalog/15058773/openapi.json)에는 **제3자 권리 포함·저작권 표시·출처표시(공공누리 제1유형)**가 안내된다. 소량 내부 샘플 조회를 넘는 원본 대량 보관·재배포 전에는 VWorld API 약관, 원천 권리 및 트래픽 조건을 확인한다. 수집 원본은 Git 제외 경로에만 둔다.
- VWorld 응답은 **법정 지정 자료**다. 서울 상주·길단위인구로 계산한 활동 패턴과는 별도 필드·출처로 보관한다. 매장 매출 변화의 원인이나 입지 적합성 점수로 바로 해석하지 않는다.

## 키 발급 후 첫 확인

1. 환경변수 이름은 `VWORLD_API_KEY`를 사용한다. VWorld가 요청 도메인 등록값을 요구하는 경우 `VWORLD_API_DOMAIN`을 별도로 받도록 한다. 키·도메인 등록 규칙·요청량 제한·사용 조건은 **발급 화면과 공식 개발 문서에서 확인**한다. 키 값을 채팅, Git, 로그, 예제 URL에 남기지 않는다.
2. 두 후보의 공식 문서와 실제 응답으로 `용도지역` 관련 레이어 ID, 주거·상업·공업·녹지의 세부 코드 및 명칭, 도시지역 밖의 분류, 공간 필터와 페이징 방식을 확인한다. 포털 제목만으로 두 후보의 데이터가 같거나 네 분류가 모두 나온다고 단정하지 않는다. 일반적인 국토계획구역이나 용도구역 결과를 도시지역의 네 분류로 해석하지 않는다.
3. 서울의 지점 2곳 이상과 경계 부근 지점, 도시지역 밖 지점으로 테스트한다. 지도 표시와 API 속성값을 대조하고, 한 좌표에 여러 도형이 반환될 때 **용도지역·용도지구·용도구역**을 섞지 않는다. 비어 있는 응답, 범위 밖, 인증 실패, 요청 제한을 구분한다.
4. 응답의 원본 도형/속성, 조회 시각, 제공처·레이어 버전, 좌표계와 변환 방법, 원본 해시를 기록한다. **조회일은 법적 효력 발생일이나 과거 최초 공개일이 아니다.** 지정일·고시일·효력일을 받을 수 있는지 확인하고 확인되지 않으면 `null`로 둔다.
5. 원본과 검증 산출물은 Git 제외 대상인 `data/raw/nationwide/zoning/vworld/<수집일>/` 아래 새 경로에 둔다. 기존 파일을 덮어쓰지 않는다. 수집기에서 키가 포함된 URL·응답을 그대로 출력하지 않고, 오류 시 원본을 합성 데이터로 대체하지 않는다.

### 키 없이 실행하는 오프라인 검증

새 수집기 `scripts/probe_vworld_zoning.py`의 파서·응답 보존·오류 처리는 합성 fixture 기반 테스트로 확인한다. 아래 명령은 실제 VWorld 호출이나 자료 확보를 의미하지 않는다.

```bash
cd /Users/factory/Documents/Projects/PickPlace/pickplace-ai
PYTHONPATH=src:. .venv/bin/python -m pytest -q tests/test_probe_vworld_zoning.py
```

키 발급 후에는 공식 문서에서 확인한 **실제 레이어 ID**를 넣어 소량만 조회한다. 아래 위치 좌표는 요청 형식의 예시이며 용도지역 판정 사례로 검증된 좌표가 아니다. macOS `zsh`에서 키를 화면에 표시하지 않고 현재 터미널 세션에 설정할 수 있다. VWorld 등록 조건에서 필요하다면 `VWORLD_API_DOMAIN`도 설정한다.

```bash
cd /Users/factory/Documents/Projects/PickPlace/pickplace-ai
read -s VWORLD_API_KEY
export VWORLD_API_KEY
PYTHONPATH=src:. .venv/bin/python scripts/probe_vworld_zoning.py \
  --layer-id '공식_문서에서_확인한_레이어_ID' \
  --lon 126.9780 --lat 37.5665
```

`--radius-m`의 기본값은 10이며 필요할 때만 조정한다. `--output`을 생략하면 UTC 날짜 기준 `data/raw/nationwide/zoning/vworld/<YYYYMMDD>/probe-<UTC 시각>.json`과 옆의 `.json.metadata.json`을 새로 생성한다. 출력 파일을 지정할 때도 기존 경로를 덮어쓰지 않는다. 이 단계에서 확인할 것은 **응답 구조와 원천 적합성**이며, 전국 수집·학습은 별도 검증 후 진행한다.

## 서비스 조회 단위와 결과 계약

| 조회 대상 | 필요한 입력·계산 | 표시할 결과와 제한 |
| --- | --- | --- |
| 선택한 매장 또는 필지 | 검증한 좌표·필지 식별자와 해당 시점의 공식 도형/속성 | 그 **위치의** 지정 용도지역, 세부 명칭, 출처, 기준일. 경계 위 다중 결과는 하나로 임의 선택하지 않는다. |
| FE가 선택한 행정동(H10) | 기준일에 유효한 H10 행정동 경계와 공식 용도지역 폴리곤의 공간 교차 | 행정동의 유형별 **면적 구성**과 미분류 면적. 한 점의 지정값을 동 전체의 유형으로 표시하지 않는다. |
| AI 활동 특성 | 인구·시간대 지표와 그 정의·관측 기간 | 관측된 주간/야간 등 활동 패턴. 공식 법정 용도지역이라는 제목이나 확률로 표시하지 않는다. |

결과에는 최소한 `status`, `reason`, `source`, `layer`, `observed_at`, `retrieved_at`, `geometry_scope`, 원본 코드·명칭과 분류된 범주를 둔다. 법적 효력일이 확인되지 않으면 별도 `effective_at: null` 및 사유를 둔다. 값이 없는 경우 `zone: null`과 안정적인 사유 코드를 반환한다. 시점이 다른 행정동 경계를 이름 또는 코드 자릿수만으로 연결하지 않는다. 원본 H10은 BE·FE 응답에서 보존한다.

## AI 학습에 넣기 전 필요한 증거

현재 VWorld 조회값은 **현재 확인된 지정 상태**로만 취급한다. 2021~2025년 서울 매출·점포 분기에 오늘 조회한 용도지역을 과거의 정답이나 특징으로 붙이지 않는다. 모델 입력으로 쓰려면 다음을 확인한다.

1. 분기별 또는 변경 이력의 법적 효력일과 당시 공개·이용 가능일, 행정동 경계 버전, 원본 공간 좌표계.
2. 당시 행정동×용도지역의 공간 교차 비율 또는 당시 선택 위치의 지정값. 혼합 지역과 미분류·경계 불일치 처리.
3. 기존 서울 매출 연구와 **같은 표본·시간순 평가**에서 매출·업종 기준선에 용도지역 특징을 더한 비교. 업종별·지역별 오차, 보류율, 새로운 기간의 평가를 기록한다.
4. 법정 지정이 매출의 원인이라는 설명이나 영향 가중치는 별도 인과 근거가 없는 한 제공하지 않는다. 성능 개선이 검증되지 않으면 용도지역은 현황 설명에만 사용한다.

[현재 서울 활동 지표 후향 실험](SEOUL_ACTIVITY_MODEL_RESEARCH.md)은 인구·시간대 자료를 추가해도 일관된 오차 개선을 확인하지 못했다. 이 실험에는 법정 용도지역이 없으며, VWorld 키 발급만으로 결과가 달라지지는 않는다. 기존 모델/API를 새 공간 자료로 자동 재학습하지 않는다.

## FE·BE 후속 이슈에 넘길 내용

- **BE:** 운영 원천 소유와 정기 수집/캐시 책임을 정한다. 키는 서버 측에서만 사용한다. 지점 조회와 행정동 면적 구성 중 제공 범위를 결정하고, 공식 경계·코드·시점 검증을 구현한다. 외부 API 장애와 자료 없음은 서로 다른 상태로 반환한다. AI 호출은 통계 읽기 트랜잭션을 끝낸 뒤 실행한다.
- **FE:** 법정 지정과 활동 패턴을 서로 다른 카드로 표시한다. 지점·필지의 지정 결과를 행정동 전체의 성격으로 표시하지 않는다. 원천·조회일·효력일 미확인과 다중/혼합 지역을 이해할 수 있는 문구로 표현한다. 브라우저 번들에 VWorld 키를 넣지 않는다.
- 상세 계약과 완료 기준은 [지역 특성 FE·BE 이슈 초안](REGION_PROFILE_FE_BE_HANDOFF.md)을 따른다. 이 문서는 해당 저장소의 변경을 수행하지 않았다.

- 공식 포털의 자료 이름·설명과 기존 PickPlace 문서·데이터 계약을 대조했다.

- 정적 검사: `.venv/bin/ruff check --no-cache .` 및 `.venv/bin/ruff format --check --no-cache .` 통과.
- 전체 테스트는 같은 환경에서 **352 passed, 12 failed**였다. 12건은 기존 `tests/test_unified_api.py`의 픽스처가 `as_of=2026-11-09`를 사용하면서 실행 시 생성하는 `created_at_utc`가 현재 날짜인 2026-11-11을 가리키는 시점 불일치에서 발생했다. 이번 추가 파일의 오프라인 검증과는 별개의 문제이며, 기존 테스트 파일은 수정하지 않았다.
- VWorld 키를 사용한 **실제 API 호출·원본 수집·모델 학습은 아직 진행하지 않았다**. 실제 응답, 구체 레이어 및 코드 체계, 시점별 지정 이력과 조회 범위도 **미확인**이다. 이 문서의 필드명·결과 계약은 제안안이다.
