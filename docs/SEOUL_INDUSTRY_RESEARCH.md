# 서울 업종 정보를 활용한 공동 모델 연구

## 목적과 접근

서울 모델의 전년 동기 대비 매출 성장률 예측 오차를 줄이기 위해 기존 매출 이력 특징과 원천 구분에 서울 서비스 업종 코드를 추가했다. 업종 범주는 학습 자료에서만 정하고, 학습에서 보지 못한 코드는 미확인 범주로 처리한다. 경기도 업종에는 서울 코드와의 대응을 추측하지 않는다. 경기 입력은 `review_only_not_training_or_prediction`으로 표시된 미승인 검토 후보로, `DATA.md`의 학습 제한과 충돌한다. 사용자 요청에 따른 기존 공동 연구를 재현하기 위한 제한적 탐색에만 사용했고, 단위·경계·집계 정의 검증 및 별도 승인 전에는 운영이나 확정적 성능 판단에 사용하지 않는다. 서울은 이전 분기 이력을 더 사용하며, 경기도는 기존 학습 범위와 원천별 50:50 가중치를 유지한다. 원본이나 평가 라벨을 임의로 제거하거나 잘라내지 않는다.

기존 API가 적용하는 서울 저매출·급변 네 신호의 **고정 기준을 분석 목적으로만** 적용해, 기준을 통과한 같은 서울 사례를 비교했다. 이는 모델을 바꿔도 API의 정책을 그대로 적용해도 된다는 뜻이 아니다. 두 모델 모두 동일하게 보류된 사례는 이 표에 포함되지 않으며, 라벨과 이력이 있는 경우만 비교했다. 평균 절대오차는 예측 성장률과 실제 성장률 차이의 평균으로 단위는 %p다.

## 2025Q4 후향 탐색 결과

| 비교 대상 | 서울 네 신호 통과 14,112건 MAE | 서울 전체 16,002건 MAE | 경기 전체 30,524건 MAE |
|---|---:|---:|---:|
| 이력 확대 공동 모델 | 20.04%p | 69.61%p | 38.35%p |
| 서울 업종 추가 후보 | 19.30%p | 68.85%p | 38.69%p |

서울 동일 제공 범위에서 중앙 절대오차는 10.87→10.30%p, 상위 90백분위 절대오차는 42.86→41.07%p였다. 이 범위는 16,002건 중 88.19%다. 기존 API의 공동 평가모델은 같은 서울 표본에서 MAE 20.19%p이며 전체 서울 MAE는 70.28%p다. 전체 오차에는 저매출 분모로 인한 큰 성장률 오차가 포함된다. 보류 범위를 좁히거나 확대해 성능을 개선한 것으로 표시하지 않는다.

서울의 2026Q2를 **이미 확인한 재사용 자료**로 같은 평가 모델에 다시 대입하면, 기준 통과 14,085건에서 22.08→21.54%p였다. 여러 번 확인한 2025Q4와 2026Q2를 바탕으로 후보를 탐색했으므로 둘 다 독립 시험이 아니다. 위 수치는 비교를 위해 2025Q2까지 학습한 평가 모델에만 적용되며 이후 2026Q2까지 다시 학습한 최종 후보의 성능을 의미하지 않는다.

서울 단독 과거 분기 탐색에서도 업종 입력 후보가 보류 기준 통과 표본의 평균 오차를 낮췄다. 서울 단독 실험은 공동 모델 평가와 구분하며, 과거 공개 상태를 입증하는 전향 검증이 아니다.

## 적용 범위와 남은 검증

경기도 오차가 이력 확대 공동 모델보다 높아졌고, 새로운 독립 분기 평가도 없어 기존 통합 FastAPI와 모델은 교체하지 않는다. 후보는 별도 연구 산출물이며 기존 서울 보류 정책은 현재 API 모델에만 지문으로 연결된다. 학습 전용 범주/모델 파일은 신뢰할 수 있는 로컬 파일만 불러온다. 체크섬은 무결성 확인이지 신뢰할 수 없는 joblib을 안전하게 하지는 않는다.

2026Q3 자료가 확보되면 고정한 각 후보를 같은 이력 완비 표본에 평가하고, 서울 네 신호 통과·전체 및 경기 전체의 MAE·중앙·p90·표본 수를 함께 비교한다. 이후 평가 구간을 보고 임계값이나 학습 설정을 바꾸면 그 기간은 더 이상 독립 시험이 아니다. 과거 데이터 공개·정정 이력, 행정동 경계, 경기 매출 단위·집계와 코드 체계, 기존 FE·BE 계약도 별도로 확인한다. 제공 이력을 기반으로 한 보류는 자료 오류나 일시적인 현상을 확정하지 않는다.

## 재실행

아래 명령은 AI 프로젝트 폴더에서 실행하며 기존 산출물을 덮어쓰지 않는다. 경기도 입력이 미승인 검토 후보임을 이해한 후 연구 목적으로만 사용한다.

```bash
PYTHONPATH=src:. OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m scripts.train_seoul_industry_research \
  --seoul data/processed/seoul/seoul-2021-2026q2-20261104.csv \
  --seoul-manifest data/processed/seoul/seoul-2021-2026q2-20261104.manifest.json \
  --gyeonggi data/processed/gyeonggi/monthly-review-20261109/candidates.csv \
  --gyeonggi-manifest data/processed/gyeonggi/monthly-review-20261109/manifest.json \
  --snapshot 2026-11-09 \
  --output artifacts/seoul-industry-research-new \
  --report reports/seoul-industry-research-new.json
```

이번 실제 연구 산출물은 `artifacts/seoul-industry-research-20261109-v2/`, 비교 보고서는 `reports/seoul-industry-research-20261109-v2.json`에 있다. 평가용 모델과 최종 재학습 후보는 별개다. 보고서에 입력 및 코드 지문, 지표, 보류 범위, 미검증 제한을 기록한다. 기존 API에 연결하지 않으며 모델과 보고서는 Git에서 제외한다.
