# 서울 매출 급변 원천자료 점검

2025Q4 공동 평가 모델의 오차 상위 12개 조합을 대상으로 서울 원본의 매출금액·매출건수·시간대·요일 구분을 확인했다. 2024·2025년 원본 CSV와 2026Q1·Q2 API 수집본의 **원본 값을 그대로** 비교했다. 원본 열 이름은 `당월_매출_금액`과 `당월_매출_건수`이며, 기준키가 연분기라는 이유로 3개월 합계라고 단정하거나 값을 곱하지 않았다. 금액/건수는 제공된 두 값의 단순 비율로, 건당 실거래금액이라고 확정할 수 없다. 시간대·주중 필드는 같은 원본의 세부 구분이므로 서로 독립적인 검증자료가 아니다.

[서울시 상권분석 서비스 소개](https://golmok.seoul.go.kr/introduce.do)는 카드사 결제금액과 지역·업종·연도별 보정비율을 이용하는 추정매출 산식을 설명한다. [행정동 추정매출 데이터 안내](https://data.seoul.go.kr/dataList/OA-22175/S/1/datasetView.do)는 2024년부터 공간 단위가 바뀌고 2026년 7월 3일부터 2021년 이후 자료를 제공한다고 안내한다. 이 설명은 아래 특정 사례에 보정 변경·공간 변경·정정이 발생했다는 증거가 아니다.

| 원본 행정동·업종 | 2024Q4 제공값 | 2025Q4 제공값 | 관찰 |
|---|---:|---:|---|
| 가락본동·의료기기 | 금액 4,329,861원, 건수 139 | 금액 8,621,077,459원, 건수 1,490 | 금액 약 1,991배, 건수 약 10.7배. 단순 금액/건수는 약 3.1만원→578.6만원. 2025Q4 시간대 14~17시 금액 비중 약 72.2%. |
| 한강로동·반찬가게 | 금액 5,336,722원, 건수 15 | 금액 2,724,650,440원, 건수 152,212 | 금액 약 510배, 건수 약 10,148배. 단순 금액/건수는 약 35.6만원→1.8만원. 2025Q4 시간대 11~14시 금액 비중 약 97.1%. |

가락본동 의료기기 금액은 2025Q3부터 2026Q2까지 높은 수준이 연속 등장하고, 한강로동 반찬가게도 2025Q1부터 2026Q2까지 높은 금액이 이어진다. 반면 군자동·시계 및 귀금속은 2025Q4 고값 이후 2026Q1에 낮아졌다. 각각의 수치는 제공기관의 추정값이며 실제 점포·카드 거래의 변화, 분류·공간경계, 표본 구성·보정계수 변경, 정정 또는 기록 오류 중 무엇이 원인인지는 확인되지 않았다.

기존 네 보류 신호를 적용한 2025Q4 평가 가능 16,002건의 사후 분석에서는 1,890건이 보류 대상이었고 총 절대오차의 74.67%를 차지했다. 오차 상위 1% 161건 중 145건이 보류 대상이었다. 각 신호는 겹치므로 개별 신호 수와 오차 기여율을 합산하면 안 된다. 직전 4개 입력 관측값 사이에 기준을 초과하는 증가가 있었던 977건 중 96건은 그 다음 관측값이 증가 전 값의 75~125% 범위로 돌아왔다. 이는 당시 목표값을 포함할 수 있는 **사후 기술통계**이자 임의의 단순 범위이며, 계절성과 기저 변화를 고려하지 않아 나머지 사례가 지속적 현상이라는 증거도 아니다.

기준·오차 집계는 2025Q4에 이미 검토한 수정 스냅샷의 후향 결과다. 라벨과 이력이 있는 표본만 포함하며 과거 최초 공개 시점, 실제 운영 성능·전체 요청 보류율, 인과관계를 입증하지 않는다. 정책 기준의 새 기간 검증 전에는 더 좁은 보류 규칙이나 과거 극단값 삭제를 정당화하지 않는다.

추가로 제공기관에 각 사례의 2024~2026년 업종별 보정비율과 변경 시점, 카드 표본·집계 대상·공간 연계와 정정 이력을 확인한다. `reports/seoul-source-diagnosis-20261109/selected_timelines.csv`에 선택 사례의 원본 필드와 단순 파생 비율을 보관한다. 모델 학습 입력이 아닌 검토 자료이며 Git 제외 대상이다. 입력·스크립트·출력 지문은 같은 폴더의 `summary.json`에 기록한다.


## 보류 정책의 업종별 영향과 추가 신호 비교

동일한 2025Q4 공동 평가모델과 라벨·이력 완비 표본에서 보류 1,890건 중 259건(13.70%)은 그 평가모델의 사후 절대오차가 10%p 이하였다. 제공된 14,112건 중 1,067건(7.56%)은 사후 절대오차가 50%p를 초과했다. 10·50%p는 설명을 위한 구간일 뿐 원본 오류·정책 정오 판정이나 최종 모델의 독립 성능이 아니다. 2026Q2는 이미 사용한 재진단이다.

| 업종 | 평가 표본 | 기존 네 신호에 의한 보류 비율 |
|---|---:|---:|
| 핸드폰 | 179 | 60.3% |
| 가전제품수리 | 83 | 53.0% |
| 시계 및 귀금속 | 234 | 46.2% |
| 인테리어 | 193 | 44.0% |

보류율은 업종 자체의 위험도나 자료 오류 비율이 아니다. 업종별로 예측 접근 범위가 달라질 수 있어 성능을 충분히 검증하지 않고 공통 기준을 강화하지 않는다. 전체 업종·지역 표는 `reports/seoul-policy-audit-20261109/`에 있다.

훈련 입력에서 정한 점포수 전분기 변동률 상위 5% 신호를 추가하면, 2025Q4의 입력·라벨·점포이력 완비 표본에서 기존 제공 14,112건(88.19%)은 13,501건(84.37%)으로 줄고 제공 건의 조건부 MAE는 20.19%p에서 19.81%p가 된다. 추가 보류 611건 중 199건의 사후 오차는 10%p 이하였다. 이는 기존 평가모델과 같은 표본의 사후 탐색이며 추가 보류의 편익이 입증됐다는 의미가 아니어서 API에 적용하지 않았다.

## 점포 이력의 모델 입력 후보

2025Q2 학습·2025Q4 검증, 동일 표본·원천별 가중치에서 서울 기준분기와 직전 분기 점포수, 증감·개폐업 비율을 특징으로 추가했다. 경기 점포 이력은 임의의 0으로 채우지 않고 결측으로 두었고 목표분기 점포수는 사용하지 않았다.

| 입력 | 서울 MAE | 경기 MAE |
|---|---:|---:|
| 기존 매출 이력 | 70.2781%p | 38.8345%p |
| 점포 수 추가 | 70.2992%p | 38.9241%p |
| 점포 수·증감·개폐업 비율 추가 | 70.3249%p | 38.9274%p |

이미 본 단일 검증분기의 탐색값이며 실제 과거 최초 공개 시점은 알 수 없다. 점포 특징 추가가 이번 평가에서 성능을 개선하지 않아 모델을 교체하지 않았다. 세 방법의 입력 SHA와 지표는 `reports/seoul-store-feature-study-20261109/`에 있다.

## 보류 이유를 설명하는 API 개선

기존 네 보류 신호나 임계값을 바꾸지 않고, `risk_details`에 해당 입력의 기간·관측값·임계값·비교 방향과 단위를 추가했다. 급증과 급감은 입력 네 분기의 연속 전환 중 가장 큰 증가·감소 구간 하나를 표시하며 동률이면 먼저 발생한 구간을 사용한다. 이 항목은 보류 조건의 근거이지 매출 변화의 원인을 확정하지 않는다. 금액·단위는 호출자가 제공한 것으로 진위를 검증하지 않으며 `input_values_verified=false`, `sales_unit_verified=false`가 유지된다. 경기 요청과 조건 미해당·모델 실패 등은 빈 배열이다.

## 재현

세 도구 모두 사용자가 보유한 신뢰된 로컬 자료를 읽으며 기존 결과를 덮어쓰지 않는다. 원본에 포함된 개별 집계값과 모델은 Git에서 제외한다.

```bash

  .venv/bin/python -m scripts.audit_seoul_transactions \
  --validation reports/seoul-unified-error-20261109/validation_rows.csv \
  --summary reports/seoul-unified-error-20261109/summary.json \
  --y2024 'data/raw/seoul/sales/서울시 상권분석서비스(추정매출-행정동)_2024년.csv' \
  --y2025 'data/raw/seoul/sales/서울시 상권분석서비스(추정매출-행정동)_2025년.csv' \
  --q1 data/raw/seoul/sales/seoul-api-sales-2026Q1.csv \
  --q2 data/raw/seoul/sales/seoul-api-sales-2026Q2.csv \
  --output reports/seoul-source-diagnosis-new

PYTHONPATH=src:. OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m scripts.analyze_seoul_guard_policy \
  --source data/processed/seoul/seoul-2021-2026q2-20261104.csv \
  --names 'data/raw/seoul/sales/서울시 상권분석서비스(추정매출-행정동)_2025년.csv' \
  --model-root artifacts/unified-growth-research-20261109 \

PYTHONPATH=src:. OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m scripts.study_seoul_store_features \
  --seoul data/processed/seoul/seoul-2021-2026q2-20261104.csv \
  --gyeonggi data/processed/gyeonggi/monthly-review-20261109/candidates.csv \
  --model-root artifacts/unified-growth-research-20261109 \
  --output reports/seoul-store-feature-study-new
```
