# PickPlace AI 멘토링 질문

> **오늘 결정하고 싶은 것:** 서울·경기 공동 모델의 방향, 서울 보류 사례의 학습 방법, 현재 자료로 가능한 성능 검증 방법

## 프로젝트 상황 요약

- **서비스:** 사용자가 지역과 업종을 선택하면 상권 진단에 참고할 정보를 제공하는 서비스입니다.
- **현재 예측 목표:** 행정동·업종별 매출의 **전년 동기 대비 성장률**입니다.
- **사용 자료:** 서울은 추정매출, 경기는 카드매출입니다. 경기 자료의 단위·집계 방식·지역 경계는 검증되지 않아 현재는 검토용 자료를 제한적인 후향 연구에 사용하고 있습니다.
- **현재 모델:** 서울과 경기 출처를 구분하고 각각 같은 가중치를 주는 공동 연구 모델입니다. 서울은 저매출이나 급격한 매출 변화가 감지되면 예측을 보류하는 기준을 마련했습니다.
- **자료 상황:** 2026년 2분기까지 확보했으며, 3분기 자료는 아직 확보하지 못했습니다.
- **현재 적용 상태:** 새로 학습한 모델은 연구용 후보이며 기존 FastAPI 모델을 교체하지 않았습니다.

## 먼저 물어볼 질문

### 1. 서울과 경기를 하나의 모델로 학습해도 될까요?

**상황:** 서울 추정매출과 경기 카드매출은 집계 방식과 대상 범위가 다를 수 있습니다. 서울과 경기의 업종·지역 코드도 다릅니다.

**멘토에게 질문**

- 서로 다른 매출 자료를 출처 구분과 가중치만으로 함께 학습하는 것이 타당할까요?
- 공동 모델 하나, 지역별 모델, 공통 부분과 지역별 예측을 나눈 구조 중 어떤 방향을 우선 검토해야 할까요?
- 공동 학습 전에 매출 정의·단위·집계 범위 중 무엇부터 확인해야 할까요?

**결정하고 싶은 것:** 공동 모델을 유지할지, 서울과 경기를 분리할지.

### 2. 보류 사례를 학습에서도 제외해야 할까요?

**상황:** 서울의 저매출·급변 이력 사례를 제외하고 공동 모델을 다시 학습했지만, 같은 사례에서 비교한 오차는 오히려 높아졌습니다. 제외한 사례는 원본에서 삭제하지 않았습니다.

| 2025년 4분기 같은 평가 사례 | 이전 업종 반영 공동 모델 | 서울 보류 통과 사례만 학습 |
|---|---:|---:|
| 서울 통과 14,112건 | 19.30%p | 19.36%p |
| 경기 전체 30,524건 | 38.69%p | 40.13%p |

오차는 **전년 동기 성장률의 평균 절대오차**입니다. 이 기간은 이미 여러 번 살펴본 후향 평가이며, 이후 2026년 2분기까지 다시 학습한 최종 후보의 독립 성능이 아닙니다.

**멘토에게 질문**

- 급변·저매출 사례를 학습에는 포함하고 실제 제공 시에만 보류하는 편이 좋을까요?
- 해당 사례를 그대로 포함하거나 제외하는 것 외에 가중치 조정 등 검토할 방법이 있을까요?
- 서울의 학습 범위를 바꿨을 때 경기 오차도 높아진 이유를 어떻게 조사하면 좋을까요?

**결정하고 싶은 것:** 학습 사례 선정과 사용자에게 결과를 제공하는 기준을 어떻게 나눌지.

### 3. 전년 동기 매출 성장률이 적절한 예측 목표인가요?

**상황:** 전년 매출이 작으면 매출이 조금만 달라져도 성장률이 크게 변할 수 있습니다. 현재의 `%p` 오차는 매출액 자체의 오차율이 아닙니다.

**멘토에게 질문**

- 창업자의 상권 판단에 성장률 수치가 적합할까요?
- 매출 규모, 증가·감소 방향, 성장률 구간 등 다른 예측 목표를 함께 검토해야 할까요?
- 작은 매출을 가진 지역·업종의 불안정한 성장률은 어떤 방식으로 다루는 것이 좋을까요?

**결정하고 싶은 것:** MVP에서 예측할 값과 그 값을 사용자에게 제공하는 방식.

### 4. 2026년 3분기 자료 없이 성능을 어떻게 검증할까요?

**상황:** 현재 확보한 자료는 2026년 2분기까지입니다. 이미 살펴본 과거 분기를 반복 사용했고, 현재 확보한 스냅샷의 과거 실제 공개·정정 시점은 확인되지 않았습니다. 최종 후보는 2026년 2분기까지 다시 학습했습니다.

**멘토에게 질문**

- 추가 3분기 자료가 없다면 현재 자료를 어떻게 시간순으로 나누어 평가하는 것이 적절할까요?
- 이미 여러 번 확인한 분기의 결과는 어떤 수준까지 해석할 수 있을까요?
- 과거 공개·정정 시점을 모를 때 데이터 누수를 점검하는 방법은 무엇인가요?
- 최종 모델 재학습 후 성능을 검증하려면 어떤 자료와 절차가 더 필요할까요?

**결정하고 싶은 것:** 현재 가능한 검증 범위와 이후 필요한 자료.

### 5. 예측 보류 기준은 어떻게 정하고 검증해야 할까요?

**상황:** 서울은 전년 동기 저매출, 최근 분기 저매출, 분기 매출 급증·급감 네 신호를 사용합니다. 기준은 이전 오차를 확인한 뒤 탐색적으로 정한 값이며, 실제 데이터 오류나 해당 지역의 위험을 뜻하지 않습니다.

**멘토에게 질문**

- 현재처럼 네 분기 이력으로 보류 여부를 판단하는 방식이 적절할까요?
- 보류 기준의 타당성을 어떤 자료와 지표로 확인할 수 있을까요?
- 특정 지역이나 업종에 보류가 몰리는지, 오차와 제공률을 어떻게 함께 점검해야 할까요?

**결정하고 싶은 것:** 보류 기준을 유지·수정하는 근거와 검증 방법.

### 6. 성능과 불확실성을 사용자에게 어떻게 보여줘야 할까요?

**상황:** 평균 오차는 일부 큰 변화의 영향을 많이 받습니다. 보류 기준을 통과한 사례의 성능도 전체 요청의 성능이나 제공률을 뜻하지 않습니다.

**멘토에게 질문**

- 평균 오차 외에 중앙 오차, 큰 오차의 비율, 예측 제공률 중 무엇을 필수로 봐야 할까요?
- 성장률을 항상 0%로 예측하는 단순 기준과 비교해 어느 정도 개선되어야 유용할까요?
- 현재 검증 수준에서 성장률 수치나 범위를 화면에 보여줘도 될까요?
- 예측 불가능할 때 `null`과 사유를 반환하고 화면에 설명하는 방식이 적절할까요?

**결정하고 싶은 것:** MVP에 표시할 정보와 표시를 보류할 조건.

## 시간이 남으면 추가로 물어볼 질문

- **행정동 변경:** 분리·통합된 행정동의 과거 매출을 어떤 시점의 코드와 경계에 맞춰 연결해야 할까요? 확인되지 않은 조합은 어떻게 처리해야 할까요?
- **업종 코드:** 서울과 경기 업종의 공식 대응표가 없을 때 어떤 수준까지 비교하거나 공동 학습할 수 있을까요?
- **데이터 품질:** 경기 자료의 중복, 결측, 매출 단위와 집계 방식은 어떤 순서로 확인해야 할까요?
- **추가 자료:** 점포 수·인구·유동인구 등 중 어떤 자료를 먼저 확보하면 예측과 상권 진단에 도움이 될까요?
- **FE·BE 연동:** 실제로 검증되지 않은 위험도·적합도 점수는 어떤 조건을 충족해야 제공할 수 있을까요?
