# 서울 상권분석 행정동 경계 원본 검토

작성일: 2026-11-12 (Asia/Seoul)

상태: **행정동 폴리곤과 매출 코드 일치 확인. 과거 시점 경계로 학습에 사용하기 전 추가 검증 필요.**

## 원천과 보관

- [서울시 상권분석서비스(영역-행정동)](https://data.seoul.go.kr/dataList/OA-22160/S/1/datasetView.do)은 서울시 상권분석에 사용하는 행정동 영역 ZIP을 제공한다. 페이지에는 주민등록 행정기관코드, EPSG:5181, 공공누리 제1유형(출처표시), 파일 수정일 **2023-10-31**, 데이터셋 갱신일 **2026-09-11**이 표시된다. 현재 보이는 ZIP은 하나다.
- 원본 `서울시 상권분석서비스(영역-행정동).zip`을 AI 프로젝트의 Git 제외 경로 `data/raw/seoul/boundaries/official_polygon/imported_20261112/source.zip`에 무손실 복사했다. `source.metadata.json`에 원본 이름·출처·해시·반입 시각을 기록했다. SHA-256: `969f7033bd3609a5fd586790f5b2cfedc638d7647ef45c78f9c75e1dabf79f68`. 다운로드 폴더의 원본은 보존했다.
- 파일 수정일, ZIP 내부 타임스탬프, 데이터셋 갱신일 중 어느 것도 **도형의 법적 효력일 또는 해당 행정동 경계의 정확한 기준일**로 확인된 것은 아니다. 메타데이터의 `geometry_asof`는 `null`, `historical_validity_verified`와 `training_eligible`은 `false`다.

## 원본과 매출 코드 대조

ZIP 무결성 검사를 통과했고 SHP·SHX·DBF·PRJ·CPG가 한 세트 들어 있다. SHP 형식은 Polygon이며 DBF와 SHX에는 각각 **425건**이 있다. PRJ는 EPSG:5181에 해당하는 Korea 2000 Central Belt이고, CPG는 UTF-8이다. DBF의 `ADSTRD_CD`는 **8자리**, `ADSTRD_NM`은 행정동 이름이다. 기존 경계 CSV가 제공한 중심점·면적과 달리 ZIP에는 실제 경계 도형이 있다.

| 매출 원본 연도·분기 | 매출에 나타난 행정동 코드 | ZIP 경계와 정확히 일치한 코드 |
| --- | ---: | ---: |
| 2021~2024년 각 연도 | 424 | 424 |
| 2025년 | 425 | 425 |
| 2026년 1·2분기 | 425 | 425 |

2021~2024년 매출에 나타나지 않으나 ZIP에 있는 코드는 `11740690`(둔촌1동) 하나다. 위 수치는 **현재 확보한 매출 표본의 코드 커버리지**이며, 모든 시기의 행정동 경계가 공간적으로 같다는 증거는 아니다. [서울시 생활인구 FAQ](https://data.seoul.go.kr/dataVisual/seoul/seoulLivingPopulation.do?testcode=0318)는 서울 8자리 행정동 코드가 행정안전부 10자리 코드의 마지막 `00`을 뺀 형식이라고 설명한다. 이 원본과 매출 원본의 결합은 자릿수 추측 없이 **8자리 값 자체의 일치**로 확인했다.

## 용도지역 학습에 앞서 확인할 조건

1. 경계 ZIP 하나의 425개 코드가 매출 표본을 모두 덮어도 2021~2026년의 **경계 도형 변동 여부**는 미확인이다. [SGIS의 연도별 읍면동 경계](https://sgis.mods.go.kr/view/pss/openDataIntrcn) 등 공식 과거 경계와 공간적 변경을 대조한다. SGIS 코드는 다른 체계이므로 이름이나 자릿수만으로 연결하지 않는다.
2. 서울시 도시지역 ZIP의 EPSG:5174 도형을 행정동 EPSG:5181 경계와 같은 검증된 좌표계로 변환하고, 경계별 주거·상업·공업·녹지의 **면적 비율과 미분류 비율**을 산출한다. 한 중심점이나 VWorld 지점 하나의 유형으로 동 전체를 지정하지 않는다.
3. 용도지역 파일별 실제 이용 가능일과 경계 기준일을 확인하고, 당시 관측 가능한 분기에만 특징을 연결한다. 파일 수정일만으로 과거 매출 시점에 이용 가능했던 자료라고 단정하지 않는다.
4. 같은 표본·시간순 평가에서 기존 매출·업종 기준선과 용도지역 특징 추가 모델을 비교한다. 데이터 품질과 오차 개선이 검증되기 전까지 학습 및 FastAPI 응답은 변경하지 않는다.

관련 도시지역 ZIP 감사는 [서울 용도지역 원본 점검](SEOUL_ZONING_ARCHIVE_AUDIT_2026-11-12.md)에 정리했다. 이 문서는 새 파일로만 추가했으며 기존 모델·API·FE·BE 파일은 수정하지 않았다.
