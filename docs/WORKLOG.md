- 사용자 요청으로 서울 행정동·커피음료 `CS100010`을 첫 실험 대상으로 선택했다. 매출·점포 2021~2025 자료 10개로 2026-11-03 단일 스냅샷을 만들었으며 원본 관측의 가용일을 과거로 소급하지 않았다.
- 원본 10개 CSV SHA-256을 기록하고 같은 조건으로 재반입한 데이터가 바이트 단위로 일치하는지, 원본 해시가 유지됐는지 확인했다. 서울시 ZIP 내부 CRC·크기와 로컬 CSV가 일치하나 과거 공개일·버전의 증명은 아니다.
- 후향 진단은 총 6,293개 표본 중 학습 3,773·검증 840·시험 840개를 이용했고 경계 2개 분기는 제외했다. 기준·Ridge·Hist를 검증 MAE로 비교했으며, 전체 우승은 recent_growth, 학습 모델 중 우승은 HistGradientBoosting이다. 세부 기간과 수치는 `MODEL_DESIGN.md`, 평가 JSON에 기록했다.
- 가용한 현재 수정본을 이용한 후향 평가이므로 실제 과거 시점 성능이 아니다. 최신 2026년 매출·점포, 과거 스냅샷·공개일, 인구·면적 결합 및 전향 평가가 남았다.
- 연구용 번들은 기존 API 로더가 거부하는 형식이며 원본·가공 데이터와 모델은 Git 제외 대상이다. 저장된 두 모델의 해시와 시험 MAE 재계산을 확인했고, 합성 단위 테스트 6개·Ruff를 통과했다.

## 2026-11-03 — 확보한 서울 CSV와 가져오기 코드 점검

- 매출·점포 10개 CSV와 상주·길단위인구·영역 CSV의 형식, 기간 및 키를 점검했다. 원본은 변경하지 않았다. 세부 행 수·결합 결과와 미확인 사항은 `DATA.md`에 기록했다.
- 실제 점포 파일의 `유사_업종_점포_수`를 기존 총 점포 수 필드의 별칭으로 인식하고, CP949 및 별칭 충돌 테스트를 추가했다.
- CSV 전체 인코딩을 청크 단위로 확인하고 행 단위로 읽도록 변경했다. 매출 전체를 메모리에 올리지 않으며, 파일 끝 인코딩 오류와 CP949 대체도 검증한다. 필터를 적용하지 않으면 결과 키와 관측은 여전히 메모리에 쌓인다.
- 실제 커피·음료 데이터 8,396행을 임시 경로로 가져와 결과를 확인했다. 현재 확보 시점으로 전부 지정하면 과거 예측 학습 표본 0건이 되는 것을 확인했다. 실제 학습이나 성능 검증은 수행하지 않았다.
- 스트리밍 전후 커피·음료 출력은 바이트 단위로 일치했고, 2025년 전체 업종 가져오기는 67,113행을 반환했다. 테스트 80개 및 Ruff 검사·포맷 검사를 통과했다. 임시 검증 산출물은 Git에 추가하지 않았다.
- 로컬 가상환경에서 누락된 editable 설치 경로 파일을 설치 기록의 SHA-256과 일치하는 내용으로 복원했다. 별도 `PYTHONPATH` 없이 Python import, CLI와 전체 테스트를 다시 확인했다. Starlette 및 로컬 CPU 코어 감지 경고 각 1건이 남았다.
- 상주인구·길단위인구·영역의 자동 결합은 미구현이다. 과거 공개 버전과 공개일, 면적 단위·기준일, 최신 분기 매출 자료 확인이 남아 있다.
