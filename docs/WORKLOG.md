## 2026-10-29 — AI 개발 기반 구성

### 요청과 범위

- 기존 AI 개발 계획을 실행 가능한 코드·데이터 준비·학습·API 구조로 구체화한다.
- PickPlace 작업 경로의 pickplace-ai 독립 폴더에 새 프로젝트를 배치한다.
- 기존 프론트엔드는 변경하지 않고 Spring Boot가 내부 AI API를 호출하도록 준비한다.
- 사용자 확인: 실제 서울시 상권 CSV는 아직 없으므로 공식 자료 확보·반입부터 준비한다.

### 구현

- Python 패키지와 잠금 제약 파일, 개발 도구·테스트 설정
- 관측·요청 검증, 분기 연산, 코드·출처·사용 가능 시점 보존
- 공통 CSV/JSON 입출력, 중복·열 오류 검증, 품질 보고서
- 서울시 매출·점포 CSV 가져오기와 정확한 키 연결
- 달력상 연속 이력, 당시 사용 가능 자료만 반영하는 공통 특징·라벨 생성
- 전체 분기별 train/validation/test, 공개 지연에 따른 표본 제외
- zero/recent 기준 모델·Ridge·HistGradientBoosting 및 선택적 LightGBM 비교
- validation 성능 기반 후보 선택, test 평가·범위별 오차 기록
- 데이터 지문·모델 체크섬·환경·범위·실험 상태를 포함한 산출물
- 초안 위험·적합도 지수, 누락 지수 null 처리, 파생 무한대 응답 방지
- TRAIN 기준 단일 특징 민감도 설명. SHAP·인과·합산 기여도와 구분
- FastAPI 상태·모델 정보·추론, 선택적 API key 및 운영 필수 인증 설정
- 합성/실제·지원 scope·모델 정보 시점·실험 승인 상태 검증
- Dockerfile·내부 네트워크 Compose, 읽기 전용 모델 마운트
- 실제 자료 확보·코드 대응·BE 응답 조합·운영 문서

### 실제 확인한 검증

| 항목 | 결과 |
|---|---|
| 단위·API·학습 테스트 | 76개 통과. 데이터 누수, 공개 지연, 코드 보존, 중복, 합성 차단, 결측, 모델 저장·로딩 포함 |

위 학습과 평가는 모두 synthetic 데이터다. 실제 지역의 예측 성능·서비스 품질을 검증한 결과가 아니다. 실제 샘플 요청·응답은 examples/에 있으며 source_kind와 경고를 함께 보존한다.

검증 시 Starlette TestClient의 httpx 사용 폐기 예정 경고 1건이 발생했다. 기능 실패는 아니며 테스트 도구 의존성 갱신 시 별도로 확인한다.
