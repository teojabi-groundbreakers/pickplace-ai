- 실제 FE·BE 네트워크 연동, Docker·AWS 배포, 과거 공개 시점·행정경계·FE H10 및 업종 코드 대응, 월별 평균 산식은 검증하지 않았다. 원본과 데이터 인덱스는 Git에서 제외한다.

## 2026-11-09 — FE 데모 기반 상권 진단 데이터 점검

- FE 데모 결과 패널과 응답 타입을 읽기 전용으로 살펴보고, 진단 항목별 필요 데이터와 AI 프로젝트의 서울·경기·전국 원본, 가공·API 상태를 [FE 진단 데이터 점검](FE_DIAGNOSIS_DATA_AUDIT.md)에 정리했다.
- 실제 원본 보유와 AI 통합 API 응답, 별도 전국 현황 API, 합성 데모를 구분했다. 월별 화면과 서울 분기 자료, 주민등록·유동인구, 데이터 원천별 업종·지역 코드 차이를 기록했다.
- 검증: FE·AI 원본과 기존 자료·API 문서를 읽기 전용 대조했다. 실제 FE·BE 연동, 데이터 수집, 모델 재학습과 배포는 수행하지 않았다. 후속 검토는 산식·코드·기준 시점·출처별 이용조건 및 결측 응답 계약 합의다.

## 2026-11-09 — 인구·정책 API 수집 준비

- KOSIS 등록 통계자료 API에서 `101/DT_1B04005N`의 지정 월 응답을 원본 필드 CSV와 출처·시점·해시 메타데이터로 저장하는 수집기를 추가했다. 등록 조건에 따른 분류 범위, 4만 셀 제한, 공표 시점 및 코드 연계는 수집 후 별도 확인한다.
- 기업마당 직접 API에서 최신 지원사업 공고의 원본 JSON, CSV, 메타데이터를 함께 보관하는 수집기를 추가했다. 직접 API와 공고의 변환·이용조건 확인을 실행 전 요구하며, 과거 전체 이력이나 집행 실적을 의미하지 않는다.
- 두 API 모두 HTTPS 및 인증키 환경변수를 사용하고 기존 파일을 보호한다. 새 수집 결과는 Git 제외 `data/` 아래에 둔다.
- 검증: 격리 복사본에서 합성 API 응답 테스트 포함 전체 317건 통과, `ruff check .` 및 `ruff format --check .` 통과. 실제 키·자료등록 ID가 없어 실제 API 호출, 인구·정책 데이터 수집 및 모델 반영은 수행하지 않았다.
- 남은 일: API 키 발급 및 KOSIS 통계 등록, 기업마당 이용조건 확인, 실제 응답·범위와 공개 시점 검증, 경기 지역화폐 API 세부 명세 확인.
